## 产品边界

Cindy 保留了用户通过 PI 加 `pi-subagents` 所能完成的功能，但拥有全部生命周期、权限、存储和 UI 契约。第三方 TUI 和斜杠命令外壳不会被嵌入。子代理始终是其父级 Cindy 任务的子任务；它不会成为 Orca 工作节点或独立的侧边栏任务。

子代理侧边栏入口和详情界面特意仅限 Pi 使用。Pi 是唯一受支持的宿主环境，其子运行能够暴露该 UI 所需的完整多代理状态、转录、结果、审批和控制契约。Claude Code 和 Codex 的收集数据可保留为内部兼容性数据，但其现有的用户可见任务卡片和侧边栏行为不会改变，也不得占用该界面。

导航或归档不会停止已分离的子任务。重新打开父任务会恢复其 Fleet 状态。删除父任务会请求停止每个活动子任务，并在运行器拥有的进程终止后移除持久化运行数据。应用退出会请求运行器拥有的停止操作，并在优雅退出路径上等待；强制更新退出会在进程退出前同步写入相同的原子停止控制。

## 持久化运行不变量

1. 批次 ID 和每个子会话 ID 均为唯一的 UUID 派生值。
2. `taskId` 是不透明查找值，绝不用作文件系统路径。
3. 宿主仅在 UUID 验证的运行目录内写入控制请求。
4. 只有运行器能向其实际生成的进程句柄发送信号；磁盘 PID 仅为诊断元数据，绝不作为终止依据。
5. 状态、结果、配置、权限和控制文件均为私有且原子替换。转录和返回结果存储有界。
6. 分离运行在父级 PI 配置目录可被移除之前，冻结其所需的模型目录、权限快照和桥接源。
7. 父级网关代理凭据仅在持久化子任务存活期间保持租约，之后即被撤销。检查失败时默认关闭。
8. 父级导航仅关闭观察器。父级删除请求停止，等待运行器拥有的终止，并仅在所有可读运行均为终态后移除运行根目录。
9. Ask/Auto 后代写入使用子 RPC 审批请求，转发到现有 Cindy 审批 UI。缺少解析器、请求格式错误、投递失败或超时均默认关闭；完全访问仍是唯一的免提示模式。
10. 设备链路和 SSH 控制必须在数据所有设备上执行。本地渲染器不得呈现针对不可达远程会话的停止操作。

## 最终验收清单

这是一个对等任务，而非分阶段交付计划。本次实验中的范围内实现已完成，包括过期/损坏运行诊断。剩余工作是验收证据，而非另一个产品阶段：

- 运行仓库相关单元测试、受影响包类型检查、迁移回放、Schema 验证和 i18n 术语表门禁；
- 在全新的隔离桌面配置文件中演练空、加载、诊断、错误、排队、多子任务、审批、停止、引导、跟进、恢复以及父级删除/退出生命周期状态，包括窄布局和浅色/深色主题；
- 完成至少两次真实的 Cindy Host 运行，并验证返回结果、完整转录、模型/思考元数据、令牌、成本、时长、工具数量、审批/控制行为以及代理凭据租约清理；
- 独立审查完整差异，并在将实验交给用户验收之前解决每个可复现的 P0-P2 发现。

专用任务/设置编辑器和结果文件导出属于产品打磨项，因为相同的结果已通过 Cindy 调度器、内联角色和标准结果复制实现。SSH 托管的 PI 是独立的、不受支持的传输边界，明确排除在本 PR 之外；设备链路读取和控制仅在数据所有设备上执行，且在宿主边界仅限 Pi。

## 必需的流程级测试

- 精确的 PI argv（`--session-id`，绝不通过 `--session` 创建）。
- 并行子任务/会话隔离。
- 父级在排队时关闭，活动子任务使用冻结路由继续运行。
- 代理凭据租约在父级关闭后仍然有效，并在终态时被撤销。
- 停止产生 `stopped` 而非 `failed`，且绝不向过期的磁盘 PID 发送信号。
- 超时阻止排队的子任务启动。
- 超大输出通过有界状态/结果文件保持可读。
- 宿主/会话重启后恢复，重新发出最新持久化状态。
- 父级删除在移除持久化文件之前停止进程树。
- 设备链路/SSH 控制绝不回退到控制器的本地文件系统。
