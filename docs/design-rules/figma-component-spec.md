# Cindy 登录新设计稿组件与色彩规范速查手册

> Figma 文件：`CINDY`，页面 `0:1 Design`。本文只记录设计规范，不改源码。所有尺寸单位均为 Figma px；实现到 375pt 移动设计宽时，可按 `Figma px / 2` 作为基础换算。

## 0. 读取口径与平台规则

### 0.1 平台差异硬规则

客户端和移动端确认共用同一套设计与组件；**hover 状态仅桌面客户端 / 桌面浏览器生效，移动端不需要也不应实现 hover 视觉差异**。其余状态 `default`、`focus`、`filled`、`error`、`disabled`、`loading`、`pressed` 双端通用。

后文组件状态表中，所有 `hover` 行均标注为「仅桌面端」。若某组件库没有 hover 变体，移动端仍不实现 hover，桌面端按默认态或等设计补稿。
