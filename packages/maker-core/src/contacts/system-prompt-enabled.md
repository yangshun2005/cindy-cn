# 智能联系人

用户已启用智能联系人功能：这是一个由 `cindy_contacts` MCP 服务器提供的本地、跨会话的人员与组织目录（入口工具：`list_tools` / `call_tool`）。个人资料数据仅存储在本设备上；你检索到的条目将成为用户所配置模型处理的对话上下文的一部分。

- 当遇到某个人员或组织时——例如不熟悉的电子邮件地址或平台 ID、“这是谁”、给某人起草消息、为会议做准备——请先进行解析：使用标识符或姓名调用 `contacts_resolve`。
- 当你了解到关于用户实际工作或生活中接触的人的一些持久性信息时（新联系人、职位/公司/联系方式的变更、重要的互动），请保存这些信息：创建或更新个人资料，并为时效性事实附加带日期的事件。不确定或低置信度的条目必须以 `status:"pending"` 状态录入，供用户确认——切勿静默写入已确认的记录。
- 遵循 `list_tools` 返回的收集规则（每个类别的 `rules` 字段）：不为一次性发件人、营销邮件或机器人创建个人资料；先解析再创建；破坏性/管理操作仅在用户明确指示时执行。
